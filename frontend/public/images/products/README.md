# Product Images Directory Structure

This directory contains product images organized by category.

## How to Add Images

1. Navigate to the category folder (e.g., `wooden-pallet/`)
2. Add your product images with the naming convention:
   - `image1.jpg` (This will be the category cover image)
   - `image2.jpg`
   - `image3.jpg`
   - ... up to `image8.jpg`

## Supported Image Formats

- JPG (.jpg, .jpeg)
- PNG (.png)
- WebP (.webp)

## How It Works

1. **Categories View**: Shows all product categories as cards
2. **All Products View**: Shows all categories in a grid layout
3. **Category Detail View**: When you click on a category, it shows all images from that category folder
4. **No Duplicates**: The system automatically removes duplicate images from display

## Automatic Display

Images added to these folders will automatically appear in:
1. Category cards on the Products page
2. Category detail view when you click on a category
3. All products view showing all categories

## Notes

- Always keep `image1.jpg` as the main cover image for each category
- Images should be high quality (at least 1200px width recommended)
- Use consistent naming conventions for best results
- Duplicate images are automatically filtered out
